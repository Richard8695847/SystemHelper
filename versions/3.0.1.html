01三个结构性变化

签名

换成小米平台密钥

CN=MIUI, O=Xiaomi。这意味着它成为由小米签名、随 ROM 分发的系统级组件，不再是联通自己塞进去的第三方 APK。系统层面的卸载难度随之上升。

代码

全量混淆

1.2 的 DeviceInfo、DeviceManager、58 个厂商适配器全部消失，被压进 a0/a1/b/b1/c0/e1/f1/g0/g1/i。连 JSON 键名都要靠 const-string 还原。

能力

接入百度定位 SDK

新增 liblocSDK8b.so（368 KB）+ libindoor.so（1.6 MB），带百度 LBS API Key，做连续 GPS 定位、室内定位与 WiFi 指纹。

一句话： 采集重心从“设备注册”转向网络质量路测——新增的 SigInfo 报文里有 TAC/CID/PCI/ARFCN/Bands/CQI/RSRP/RSRQ/SINR、上下行速率、掉话原因、数据失败原因、EPS Fallback、经纬度、海拔、区县、速度、方位角、BSSID、SSID。

02新增 / 删除 / 提速

方向内容影响
新增SigInfo 信令快照，30 分钟一次精确位置 + 无线环境画像
新增百度定位 SDK（21 个百度地图/定位域名）室内外连续定位
提速应用清单 7 天 → 24 小时采集频率 ×7
新增0–24 小时随机抖动（new Random().nextInt(86400000)）规避周期分析
删除MSISDN 引用 6 处 → 0，getLine1Number() 4 处 → 0明确的合规收敛
收紧本地队列 100 条 → 10 条，先删后发减少本地取证痕迹
收紧MCC 门：MNC 必须以 460 开头但异常路径直接 return TRUE，门可失效
“先删后发”值得单独看： HistoryPostThread 每次取最新一条、发送前先删除。这意味着即使事后检查设备，也几乎抓不到待发内容——它主动抹掉了本地痕迹。

05自查与处置

# 版本（注意：同版本号可能对应不同 OEM 批次的重打包）
adb shell dumpsys package com.mobiletools.systemhelper | grep versionName

# 它是否在跑、有无待触发闹钟
adb shell ps -A | grep systemhelper
adb shell dumpsys alarm | grep systemhelper

# 停用 + 撤权限（对平台签名组件，停用可能被系统拒绝）
adb shell pm disable-user --user 0 com.mobiletools.systemhelper
adb shell pm revoke com.mobiletools.systemhelper android.permission.READ_PHONE_STATE
adb shell pm revoke com.mobiletools.systemhelper android.permission.ACCESS_FINE_LOCATION

# 网络层拦截——对平台签名组件同样有效，是唯一不依赖系统授权的手段
0.0.0.0 dm.wo.com.cn
关键判断： 3.0.1 起组件用小米平台密钥签名，am force-stop 或 pm disable 可能被系统策略拒绝。封域名最稳——一次覆盖 :18080。
