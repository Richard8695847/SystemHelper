01它是谁

不是应用商店里的 App，而是出厂镜像里的采集模块。

  • 权限暴露了安装位置。 READ_PRIVILEGED_PHONE_STATE 只有 priv-app 或平台签名的应用能拿到；PACKAGE_USAGE_STATS、QUERY_ALL_PACKAGES 用来读应用清单。
  • 零界面。 全包唯一的 Activity 是 TestActivity（调试页），没有设置页、没有开关、没有隐私弹窗。
  • 签名是联通自签证书。 CN=NewDM, OU=RI, O=CU, L=BJ, ST=BJ, C=86，有效期 50 年——典型的内部自签调试证书，不是发布证书。
  • 四类组件在跑。 OnBootReceiver、SIMStateReceiver、ConnectStateReceiver、ScheduleRegisterReceiver，加上 RegisterJobService 保活。

02采了什么

注册只需要 IMEI + ICCID + MNC + 机型 + 制式。它采的远不止这些。

类别字段说明

网络MNC NCLS CellID LAC VolteEnabled 5GEnabled基站与制式状态
位置SignalInfo 内的经纬度GPS 派生
应用AppInfo：包名、名称、前台时长、启动次数、分卡/分 WiFi 上下行流量周期 7 天

历史History一次最多补交 100 条旧报文
手机号这一项要单独说： 1.2 通过 getLine1Number() 读 MSISDN。实名制下这直接把设备标识与自然人绑定。3.0.1 把 6 处引用删到 0——这是三版里最明确的一次合规收敛。

04链路与加密

项实现
端点POST http://dm.wo.com.cn:18080/registerv3（唯一活跃接口）
对称加密AES-ECB / PKCS5，16 字节密钥 = MD5(明文)
密钥封装sign = URLEncode(Base64(RSA_pub(pub.cer, key)))，RSA-1024
传输明文 HTTP，usesCleartextTraffic="true"
本地留存明文 SQLite 最多 100 条，含 IMEI / 号码
 
key  = MD5(json)                    # 16B —— 密钥由明文推出，等于没有密钥
body = AES-128-ECB(key, json)       # 无 IV、无认证
sign = Base64(RSA_pub(pub.cer, key)) # 公钥随包分发，任何人可重算

另有 5 条链路（/public/ip、:6002/getRegisterLog、BONC SOAP、cnc-labs.eicp.net、webservice.chinaunicom.com），交叉引用确认全部无调用点。

05这一版独有的问题

密钥

密钥 = 报文自身的 MD5

拿到密文就能算出密钥，等于零加密。这是“自制加密”的典型反例。

传输

全程明文 HTTP

没有 TLS，任何同网段都能读到完整 JSON。
